# Batho v2 (enterprise-ready) backlog

Goals: extend Batho for production/enterprise readiness while preserving v1 accuracy and CLI ergonomics.

## Core indexing & graph
- Incremental indexing: true PR diff application (replace `incremental_patch_stub` with selective graph updates, cache reuse, and correctness checks).
- Persistent graph storage: optional on-disk/DB backend for large repos with versioned snapshots.
- Parallel extractors: tune pool sizing & backpressure; add per-language limits.
- Cross-file resolution: richer import/module resolution (Python, TS/JS, Java) with fallback strategies.

## CLI & automation
- Webhook integration: real GitHub/GitLab webhook handling (push/PR) with queueing, auth, and rate limits.
- CI pipeline hooks: turnkey GitHub Actions/GitLab templates to run `index`, snapshot, and publish artifacts.
- Progress telemetry: structured progress events for UI/CI consumption.

## Outputs & compression
- Smarter architecture.md compression: adaptive token budgeting with section prioritization and truncation hints.
- Per-language summaries: optional language-scoped reports (Python/TS/etc.) with key entities/dependencies.

## Language support
- Extend tree-sitter language coverage with additional grammars (e.g., Elixir, COBOL) and parser availability checks.
- Heuristic tuning: improve detector confidence thresholds; plug in ML-based classifier as optional addon.

## Stack & dependency intelligence
- Monorepo/polyglot/vendor-aware stack detection refinements; stronger heuristics for nested packages.
- Vulnerability/license flags: surface SPDX licenses and basic security hints from manifests (non-blocking).

## Reliability & observability
- Structured metrics: Prometheus-friendly counters/timers for indexing, cache hits, errors.
- Health checks: self-check command to validate parsers, config, and ignore rules.
- Robust error surfacing: per-file error report artifact with retry guidance.
- Performance regression baselines: CI-friendly thresholds with environment-aware slack to prevent flaky perf gating.

## Security & governance
- Authenticated endpoints: lock down webhook/daemon endpoints with tokens/signatures.
- Data minimization: configurable exclusion of sensitive paths/patterns beyond ignore files.

## UX & docs
- Rich CLI help with examples and presets (fast mode, deep mode, large monorepo mode).
- User guide for integrating Batho artifacts into review/onboarding workflows.
- Test execution guide: document `fast/slow/integration` markers and recommended `uv` commands.
